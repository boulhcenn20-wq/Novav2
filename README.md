# NOVA V2 — GitHub Pages Website

Files:
- index.html
- style.css
- script.js
- robots.txt
- sitemap.xml
- favicon.svg

## Before publishing
1. Open `script.js`.
2. Replace:
   `const WHATSAPP_NUMBER = "212XXXXXXXXX";`
   with your WhatsApp number in international format, without `+` or spaces.
3. If your final domain is different, update the canonical URL in `index.html` and the URL in `robots.txt` and `sitemap.xml`.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
